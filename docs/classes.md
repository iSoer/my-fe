# Классы

В игре 54 класса из Fire Emblem: Fortune's Weave (FW), по пяти ярусам. Набор классов, их требования к рангам навыков, оружие и тип движения задаёт модель персонажа [src/shared/character/classes.ts](../src/shared/character/classes.ts). Игровой слой [src/game/content/classes.ts](../src/game/content/classes.ts) только ищет по ней, делает из класса боевой `ClassDef` и пояснения для UI, а множители статов берёт из [content/classStats.ts](../src/game/content/classStats.ts). Отдельной механики повышения класса (promotion) нет. Класс меняется бесплатно, когда он открыт по уровню и рангам (`reclassUnit`).

## Две части одного класса

| Слой                           | Файл                                                              | Что задаёт                                                                                                                                                                                                                                                                                                                                                                                      |
| ------------------------------ | ----------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Модель (общая с next-instapok) | [shared/character/classes.ts](../src/shared/character/classes.ts) | `CHARACTER_CLASSES`: `id`, английское `name`, `tier`, требования `all` (все) и `any` (хотя бы одно). Отсюда выводятся `weaponsOf` (оружейные навыки из требований), `movementOf` (`flying` → flier, `riding` → cavalry, `heavyArmor` → armored, иначе infantry), `mountOf` (cavalry → `horse`, flier → по таблице `FLIER_MOUNTS`), `canTakeClass`, `availableClasses`, `isUniqueClass` (divine) |
| Игра                           | [content/classes.ts](../src/game/content/classes.ts)              | `fwClass(id)` (бросает ошибку на неизвестный id), `classDef(id, weaponSkill)` → `ClassDef { id, name, tier, moveType, weaponSkill }` (кэш по паре), `MOVE_RANGE` (`infantry 3, armored 2, cavalry 4, flier 3`), `DANCER_CLASS = "dancer"`, `classRole` (роль выводится из оружия, движения и множителей), `classInfo` (всё для карточки класса), `movementLabel`/`moveTypeLabel` (RU/EN)        |
| Игра: статы                    | [content/classStats.ts](../src/game/content/classStats.ts)        | `CLASS_STAT_MODS[id]`: множители статов в процентах. Они действуют и на статы 1-го уровня, и на проценты роста (см. [progression.md](progression.md)). Защиты ограничены +30 %, а у божественных классов отдельные значения доходят до +40 %                                                                                                                                                    |
| Арт                            | [art/outfits.ts](../src/game/art/outfits.ts)                      | `CLASS_OUTFITS[id]`: наряд класса (см. [art-characters.md](art-characters.md))                                                                                                                                                                                                                                                                                                                  |

Названия классов не переводятся: `CharacterClass.name` всегда английское, как в FW. По-русски выводятся только роль, тип движения и животное.

В модели есть ещё свой бонус класса: `classBonusOf` и `statsInClass` (плоская прибавка за ярус плюс сдвиг профиля). Он используется только в поле `stats` результата `generateCharacter`. Игра это поле отбрасывает и считает бой через `CLASS_STAT_MODS`.

## Ярусы

`TIER_LEVELS`: `beginner` 1, `specialty` 10, `advanced` 20, `master` 35, `divine` 60.

- Каждый боец начинает в стартовом классе (`STARTER_CLASSES`: Soldier, Hunter, Mage, Healer, Gladiator).
- Требования FW урезаны функцией `reachable`: класс никогда не требует больше, чем талант успевает набрать к открытию яруса (`rankAtLevel("talent", TIER_LEVELS[tier])`). Поэтому в таблице ниже, например, Myrmidon требует `Sword D+`, а не C, как в FW.
- Божественный класс в армии может быть только у одного бойца (`isUniqueClassId`, проверка в `reclassAction`). Божественные классы не выпадают новобранцам и врагам: их исключает `loadoutsAt`.

## Базовые статы и рост

Своих базовых статов и процентов роста у класса нет. Их задаёт персонаж: `baseStats`/`maxStats` из модели или пресета, а проценты роста — `growthRates`. Класс влияет на них двумя путями:

- `CLASS_STAT_MODS` умножает статы 1-го уровня и проценты роста (`1 + mod / 100`);
- `classPresetStats(classId, rarity, seed)` ([core/units/proficiency.ts](../src/game/core/units/proficiency.ts)) строит профиль новобранца игрока: ровный профиль плюс `CLASS_PRESET.shift` (2.5) × средний сдвиг навыков класса (`meanSkillShift(requiredSkillsOf(cls))`, таблица `SKILL_PROFILE_SHIFTS` в [shared/character/skills.ts](../src/shared/character/skills.ts)). На 1-м уровне профиль сглажен на 50 % (`baseFlatten`), бюджет равен среднему для звезды. Пример: Soldier 1★ на 80-м уровне — HP 35, Str 21, Mag 6, Spd 8, Def 17, Res 10 (боевая шкала, без множителей класса).

## Владение оружием и смена класса

- Ранг навыка (E, E+, D, D+, C, C+, B, B+, A, A+, S) выводится из `unit.skillXp` (подробности — в [progression.md](progression.md)). Класс открыт, если `level ≥ TIER_LEVELS[tier]`, выполнены все `all` и хотя бы одно `any` (`canTakeClassWith`, `classesOpenTo`, `classShortfall` — чего не хватает).
- `reclassUnit(unit, classId)` бросает ошибку, если класс закрыт. Оружие при смене класса остаётся в лапах: класс меняет движение и множители, а навык боя по-прежнему задаёт оружие. `withClassAssist` выдаёт `as_dance` для Dancer или `as_heal` при White Magic и снимает Поддержки, которые классу недоступны (`staffOnly`, `dancerOnly`).
- `equipWeapon` даёт сражаться любым оружием, а насколько хорошо, решает ранг этого навыка (`weaponShortfall`: −2 Mt за каждую недостающую ступень).
- `hasClassUpgrade` показывает в UI «есть класс выше яруса». Панель выбора класса — [ui/components/CharacterPanels.tsx](../src/game/ui/components/CharacterPanels.tsx).
- Склонность класса к навыкам (`classAffinity`, `CLASS_AFFINITY`): единственное оружие класса и его навыки передвижения ×3, одно из нескольких оружий ×2, всё прочее ×1.

## Как модель выбирает класс

`generateCharacter` в [src/model/character-model/generate.ts](../src/model/character-model/generate.ts):

- Заданный класс: `neededTalents` подбирает таланты, без которых класс не открыть на этом уровне. Если их больше `MAX_TALENTS` = 3, `validateCharacterRequest` отклоняет запрос, и `loadoutsAt` такой класс пропускает.
- Без заданного класса: выбирается из `availableClasses(aptitudes, level)` с весом `(индекс яруса + 1)²` (`CLASS_TIER_POWER = 2`).
- Комплекты `loadoutsAt(level)` (класс × оружие класса) дают вес `(ярус + 1)² / число оружий`. На 1-м уровне таких комплектов 9, на 80-м — 76.
