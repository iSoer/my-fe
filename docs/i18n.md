# Локализация

Интерфейс двуязычный: английский (по умолчанию) и русский. Строки не выносятся в словари, оба варианта пишутся прямо на месте: `tr(en, ru)`. Язык хранится в сейве (`settings.lang`), а атом `$lang` его зеркалит.

## API

[src/game/i18n/index.ts](../src/game/i18n/index.ts):

| Символ                                                                   | Назначение                                       |
| ------------------------------------------------------------------------ | ------------------------------------------------ |
| `type Lang = "en" \| "ru"`, `LANGS`, `DEFAULT_LANG = "en"`, `LANG_NAMES` | Языки и их названия для переключателя            |
| `$lang`, `lang()`                                                        | Текущий язык                                     |
| `setLang(next)`                                                          | Ставит `$lang` и `document.documentElement.lang` |
| `tr(en, ru)`                                                             | Строка на текущем языке                          |
| `plural(n, [one, other], [один, несколько, много])`                      | Форма слова, число подставляет вызывающий        |

## Как язык попадает в игру

- Источник истины — `settings.lang` в сейве. В [state/save.ts](../src/game/state/save.ts) есть подписка `$save.subscribe(s => setLang(s.settings.lang))`, так что загрузка, импорт, сброс, облако и Настройки меняют язык одинаково.
- Сейвы, сделанные до выбора языка, получают `lang = DEFAULT_LANG` через `.default()` в `settingsSchema`.
- `Router` в [App.tsx](../src/game/ui/App.tsx) пересоздаёт экран при смене языка (`key` с `lang`). Компоненты вне `Router` подписываются сами через `useStore($lang)`: так делают `Splash` и хостовый `PwaBanners`.
- `ConflictScreen` показывается до загрузки сейва, поэтому `main.tsx` сначала вызывает `setLang(conflict.local.settings.lang)`.

## Соглашения

- Вызывайте `tr()` в момент показа: в рендере, геттере или функции. **Не вызывайте** его при загрузке модуля, иначе строка застынет на языке по умолчанию. Например, `MenuScreen` генерирует демо-тройку при показе, чтобы имена были на текущем языке.
- Порядок аргументов всегда `(en, ru)`.
- Числа подставляйте в обе строки шаблоном: ``tr(`Squad holds at most ${n}`, `В отряде не больше ${n}`)``. Для склонений используйте `plural`.
- Ошибки, которые видит игрок (`{ ok: false, error }` из действий `state/*`, `parseSave`), тоже идут через `tr`.
- Комментарии и имена тестов пишутся по-русски и не переводятся. Это не пользовательский текст.
- Смоук-тесты ищут кнопки по английским подписям («Tap to start», «New game»). Если меняете такую подпись, обновите [tools/smoke*.mjs](../tools).

## Где менять

- API и список языков: [src/game/i18n/index.ts](../src/game/i18n/index.ts). Новый язык: добавить в `Lang`, `LANGS`, `LANG_NAMES` и в `z.enum` поля `lang` в `settingsSchema` ([core/save/index.ts](../src/game/core/save/index.ts)). Сигнатура `tr(en, ru)` рассчитана на два языка, поэтому третий язык потребует менять все вызовы.
- Переключатель языка: [SettingsScreen.tsx](../src/game/ui/screens/SettingsScreen.tsx).
- Тесты: [tests/game/i18n.test.ts](../tests/game/i18n.test.ts).
