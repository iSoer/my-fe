# Вылазка в мрачную чащу («большая карта»): поле 30×30

Режим `expedition` («Мрачная чаща») — это не карта мира из узлов, а **одно большое тактическое поле 30×30**.
Схема в духе Dota:

- старт в левом нижнем углу, три выхода в остальных углах;
- три дороги (верхняя, средняя, нижняя) и ручей поперёк средней дороги;
- лагеря стражей с сундуками в лесу.

Цель боя `extract`: забрать ключ у стража, открыть сундук и уйти через любой выход. Пока враги спят, идёт **разведка**: отряд ходит по карте свободно, без ходов; упёрся в зону тревоги — начинается пошаговый бой (раздел «Разведка и бой»). Уйти можно и не открыв ни одного сундука — тогда без их содержимого. Генератор детерминирован
по `seed`, связность каждой попытки проверяется.

## Константы (`EXPEDITION`)

| Поле                                        | Значение                                                                                                         |
| ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `w × h`                                     | 30 × 30 (тест требует квадрат площадью около 2 × 18×24)                                                          |
| `chests` (лагеря)                           | easy 4, normal 5, hard 6, nightmare 6                                                                            |
| `group` (стражей в лагере)                  | easy 2–3, normal 2–4, hard 3–4, nightmare 3–4                                                                    |
| `leash` / `alertRadius`                     | 5 / 6 (радиус тревоги шире обзора — часть стычек начинается с невидимого врага)                                  |
| `vision`                                    | 3 — туман войны: радиус обзора бойца (круг); выходы тоже скрыты, пока их не найдут                               |
| `elites` / `eliteLevelBonus` / `eliteLeash` | 2/3/3/4 / +3 уровня / 3                                                                                          |
| `exitGuards` / `exitGuardLeash`             | 2 из 3 выходов / 3                                                                                               |
| `hearts`                                    | 5                                                                                                                |
| `chestKinds`                                | treats 2, weapon 1, talisman 1                                                                                   |
| `chestShare`, `chestSpread`                 | 0.6 от `teamTreats` на трёх стражей, разброс ±15 %                                                               |
| `itemBand`                                  | easy [0, 0.35], normal [0.25, 0.6], hard [0.5, 0.85], nightmare [0.7, 1] (доля списка, отсортированного по цене) |

`BUFF`: `fury` +20 % урона, `aegis` −20 % получаемого урона, `swift` +2 клетки хода отряду, `fortune` ×1.5 добычи.
Бонуса «Живица» (`regen`) больше нет: сейв v13 убирает его из идущей вылазки.

Лимита ходов в чаще нет: `turnLimitOf` для `mode: "expedition"` возвращает `Infinity`, отряд уходит сам через выход
(в схватке по-прежнему `BATTLE.turnLimit = 20`).

## Структура поля

- **Старт**: якорь `(2, h−3)`. Спавны игрока по порядку: (1,h−2), (2,h−2), (1,h−3), (2,h−3), (3,h−2), (3,h−3).
- **Выходы**: `exits[0] = (w−1, 0)` — главный, в него сходятся все три дороги. Ещё два выхода: `(0, 0)` и
  `(w−1, h−1)`.
- **Дороги**:
  - `top`: через (2, h/2), (2, 2), (w/2, 2);
  - `bottom`: через (w/2, h−2), (w−2, h−2), (w−2, h/2);
  - `mid`: 6 точек по диагонали от старта к выходу с разбросом ±2.
  - Боковые выходы соединяются короткой тропой с ближайшей клеткой дороги.
- **Ручей**: лестница из пар клеток по диагонали от `t = 4` до `w − 6`, изгибы ±2.
  - Там, где ручей пересекает дорога, `carve` ставит мост (`decor = "bridge"`, клетка `plain`). Переход по воде
    стоит дороже (`waterCost` 4, между лагерями 3).
  - Ещё 2 брода ставятся не ближе 6 клеток к мостам.
- **Препятствия**: груды валунов (`mountain`, `round(w·h·0.015)` штук по 2–4 клетки) и вековые стволы (`wall`,
  `round(w·h·0.01)`). Поляны радиусом 3 вокруг старта и выходов.
- **Лагеря** (`pickCamps`):
  - в пределах `[3, w−4]`;
  - не ближе 10 клеток к старту и 7 к выходам;
  - не ближе 9 друг к другу;
  - не ближе 3 к тропе и воде.
  - Ограничения ослабляются за 4 прохода.
  - Ромб радиусом 2 вокруг лагеря расчищается. Тропа ведёт от ближайшей точки дорог, с вероятностью 60 % есть
    ещё тропа к соседнему лагерю.
  - Рядом 1–2 укрытия: 70 % `cover`, 30 % `wall_breakable`.
- **Проверка**: из старта пехотой достижимы все выходы и все лагеря. Иначе попытка возвращает `null`.

## Алгоритм `generateExpedition`

1. До 30 попыток `terrainAttempt(root.fork("terrain:N"))`. Если ни одна не прошла, `fallbackTerrain`
   (`fork("fallback")`) строит плоскую поляну без препятствий и ручья (связность гарантирована) и прокладывает
   по ней дороги и лагеря. Хотя бы один лагерь есть всегда: если `pickCamps` не уложилась в ограничения, лагеря
   ставятся детерминированно в самых удалённых от троп клетках (иначе без сундука из чащи не уйти).
   Дальше считается `reach` от старта: стражи лагерей и выходов, одиночки и сердечки ставятся только на
   достижимые клетки (недостижимые отсеиваются после перемешивания, порядок случайных чисел не меняется).
2. **Стражи** (`fork("enemies")`):
   - на каждый лагерь `erng.int(group)` врагов на ближайших свободных клетках в 1–3 шагах (`guardSpots`);
   - стойка `hold`, `post` — сундук, `leash = 5`;
   - у одного из них `keyHolderId`.
3. **Сундук** (`ExpeditionChest`): `{ id: "chest_i", pos, kind, treats, keyHolderId, itemId? }`.
   - Сундук с Вкусняшками содержит `round(teamTreats × 0.6 × стражей/3 × jitter)`.
   - Сундук с предметом получает `chestItem()`: оружие с `price > 0` или талисман из `itemBand`.
4. **Одиночки-вожаки** (`fork("pickups")`):
   - ставятся через `spread` с шагом 7, не ближе 6 к лагерям, 9 к старту и 5 к выходам;
   - уровень `maxLevel + 3`, `isBoss: true`, `leash = 3`;
   - у каждого свой бонус из перемешанного `BUFF_KINDS`. После смерти бонус падает на его клетку
     (`buff_<unitId>`).
5. **Сердечки**: 5 штук на клетках `decor` с шагом 6, не ближе 7 к старту. Тот, кто встал на сердечко,
   полностью восстанавливает HP.
6. **Стражи выходов** (`fork("exit-guards")`): 2 случайных выхода из 3, по одному врагу, `leash = 3`.
7. Результат: `objective: "extract"`, `mode: "expedition"`, `expedition: { chests, exits, pickups, elites }`,
   `reinforcements: []`, `rewards: { treats: teamTreats, glory }`.

## Прогрессия и награды в бою

Правила в `reducer.ts`, шаг вылазки `expeditionStepOn` и действия `openChest` / `extract`:

- Ключ получает боец, который убил носителя. Если носитель погиб иначе, ключ падает на клетку и подбирается
  шагом.
- Боец с ключом встаёт на сундук — игра спрашивает «Открыть сундук?». В разведке ключ общий на весь отряд: спросит,
  на какого бы бойца ни встал на сундук, если ключ у кого-то из живых бойцов (`chestToOpen`); в бою — только у носителя. «Да» — действие `openChest`: вкусняшки
  попадают в `stats.loot`, предмет — в `expedition.found`; ход бойца не тратится.
- Боец встаёт на выход (перестановкой или завершив действие) — игра спрашивает «Завершить вылазку?». Открытый
  сундук не нужен: без него окно предупреждает, что отряд уйдёт без содержимого сундуков. «Да» — действие
  `extract`: победа, находки (если есть) переходят армии.
- Выходы светятся всегда; пока не открыт ни один сундук — бледнее.
- «Нет» просто закрывает окно. Спросить снова — тап по бойцу на этой клетке (выбранному или уже ходившему).
  Пока окно открыто, поле не принимает тапов и ход сам не завершается (`autoEndTurn` ждёт ответа).
- Перебить всех врагов недостаточно: `checkEnd` для `extract` не даёт победы.

## Туман войны

Файлы: `initFog`, `reveal`, `revealSquad`, `isRevealed` в [core/battle/explore.ts](../src/game/core/battle/explore.ts),
`syncFog`, `peekFog`, `clearFog` в [MapScene.ts](../src/game/scene/MapScene.ts).

- `BattleState.revealed` — строка из `"0"`/`"1"` по `y * w + x`; нет поля — тумана нет (вне чащи и в бою из сейва до
  v14). `createBattle` в чаще вызывает `initFog`: открыт только круг `EXPEDITION.vision = 3` вокруг каждого бойца. Выходы
  скрыты, как и всё остальное: их подсветка и табличка появляются, когда клетку выхода разведают.
- После каждого действия (`applyAction`) открывается обзор вокруг живых бойцов отряда и вдоль всех их путей
  (`moved` бойцов игрока и `squadMoved`). Разведанное не закрывается.
- Встал перед зоной тревоги — враг, чья зона сработала, открывается (`reveal` радиусом 1): видно, почему отряд встал.
- На правила туман не влияет: ИИ, пути и зоны считаются по всем врагам. Он скрывает только то, что видит игрок:
  - сцена: серый туман — `RenderTexture` (`FOW_RES = 16` пикселей на клетку) из тёмно-серой подложки
    (`FOW_BASE`, `FOW_BASE_ALPHA = 0.88`) и бесшовной облачной текстуры `map:fowCloud` (фрактальный шум, рисуется один
    раз, `ensureFowCloudTexture`) на глубине 1.95 — над
    тайлами, сундуками и дымкой тревоги, под подсветкой хода и бойцами; разведанное стирается мягкими пятнами. Враги,
    сундуки, ключи и бонусы в тумане не рисуются. Пока бойцы отряда идут, туман рассеивается на каждом их шаге
    (`peekFog` из `presenter.moved`) и проявляется за ~0.2 с; камера не наезжает на врагов в тумане;
  - интерфейс: враг в тумане — пустая клетка (`visibleFoe`): ни сведений, ни цели атаки, ни зоны опасности; дымка
    тревоги — только от видимых врагов и только на разведанных клетках (зона врага в тумане не показывается —
    на него можно наткнуться неожиданно); справка о клетке — «Неразведано». Тап по клетке в тумане в разведке
    ведёт отряд туда (недостижимая — к ближайшей достижимой).

## Разведка и бой

Файлы: [core/battle/explore.ts](../src/game/core/battle/explore.ts) (зоны тревоги), `exploreMove` и `enterExplore` в
[reducer.ts](../src/game/core/battle/reducer.ts), `tapExplore` и `exploreTo` в
[state/battleUi.ts](../src/game/state/battleUi.ts), событие `squadMoved` в [presenter.ts](../src/game/scene/presenter.ts).

- **Зона тревоги** (`alertZone`) — клетки, встав на которые боец игрока разбудит спящего врага (`isAsleep`: стойка не
  `advance`). Это ровно условия `shouldWake` у ИИ без «шума боя»: ромб радиуса `alertRadiusOf` (у стражей с постом —
  `EXPEDITION.alertRadius = 6`) плюс зона атаки врага (`threatTiles`). Тест сверяет зону с решениями ИИ клетка за клеткой.
- **Разведка** (`BattleState.explore = true`): ходов и фаз нет, `endPhase` и пошаговые действия бросают исключение.
  Действие `explore { unitId, to, solo? }`:
  - ведущий идёт к клетке без ограничения дальности — в обход зон тревоги, если так можно дойти (`reachableTiles` с
    `avoid`); иначе по кратчайшему пути, но встаёт на последней клетке **перед** зоной. Недостижимая клетка (её
    обступили враги) — путь к ближайшей достижимой;
  - без `solo` остальные бойцы идут следом: ближние к ведущему первыми, каждый на свободную клетку вне зон как можно
    ближе к нему;
  - событие `squadMoved` (все пути разом), затем `expeditionStepOn` для каждого: ключи, сердечки, бонусы;
  - упёрлись в зону — `explore = false`, событие `alarm`: пошаговый бой, ход игрока, враги ещё спят.
- **Бой → разведка**: после фазы врага (`endPhase`), если `isCalm` (нет проснувшихся врагов и никто из отряда не стоит
  в зоне тревоги) — `enterExplore`: `explore = true`, бойцы сброшены (`acted`, бонусы, штрафы), событие `calm`. Иначе
  обычный ход игрока. Счётчик ходов растёт только в бою.
- Вылазка начинается с разведки (`createBattle`), если отряд не стоит в зоне тревоги.
- Чтобы бой кончался, проснувшиеся стражи не должны «зависать»: ИИ возвращает их на пост и усыпляет, когда отряд не
  достать (край поводка, перекрытый путь), когда страж ранен и когда лекарю или танцору некого поддерживать в бою
  (см. [ai](ai.md), «Страж без целей»). Действие врага целиком в тумане войны проигрывается мгновенно — без пробежки
  невидимки.
- Интерфейс: тап по клетке — отряд идёт за ближайшим к ней бойцом; выбранный боец (тап по нему) или перетащенный идёт
  один. Тап по врагу — сведения, по непроходимой клетке — справка. Подсветки дальности в разведке нет, «Завершить ход»
  недоступна, в шапке «Разведка». Зоны тревоги спящих врагов видны всегда (и в бою): едва заметная фиолетовая дымка
  (`MapScene.drawAlert`: мягкие пятна в `RenderTexture` по `FOG_RES` пикселей на клетку, растянутой на поле; прозрачность медленно «дышит»). Отряд бежит в `EXPLORE_SPEED = 2.5` раза быстрее обычного, шаги слышно только у ведущего;
  баннеры «Враги рядом!» (`alarm`) и «Опасность миновала · Разведка» (`calm`).

## Как узел становится боем

Узлов как таковых нет. На шаге 1 `BattleSetupScreen` выбирается режим `$sortieMode = "expedition"`. Дальше
`enemyTeams(difficulty, "expedition")` создаёт 4 карты чащи с seed
`createRng(sortieSeed).fork("${difficulty}:${team}:expedition")`. Остальной путь общий со схваткой:
`scoutBattle` → `pendingBattle` → `startBattle`.

## Где менять

**Рецепт: новый вариант большой карты** (новая форма или тип вылазки).

Сейчас вариант ровно один, а `generateExpedition` жёстко задаёт биом, размер и схему. Минимальный путь:

1. Константы: вынести параметры в `EXPEDITION` ([balance.ts](../src/game/content/balance.ts)) или завести
   соседний объект, например `EXPEDITION_SHAPES: Record<ExpeditionShape, {...}>`. Там задаются `w`, `h`,
   число лагерей и т. п.
   - `river()` идёт по диагонали через `size.w` и растягивает её по высоте (`(h−1)/(w−1)`), так что работает и
     на прямоугольном поле; углы с выходами для другой формы нужно проверить.
2. Генератор: в [core/map/expedition.ts](../src/game/core/map/expedition.ts) добавить параметр в
   `GenerateExpeditionOptions` (например `shape`).
   - Ветвить `terrainAttempt` по форме: другие опорные точки дорог, другие `start` и `exits`, без ручья и т. д.
   - Заканчивать попытку проверкой `reach(...)` для всех выходов и лагерей.
   - Новый биом задаётся заменой `EXPEDITION_BIOME` на параметр. Тогда в `LAYOUT_WEIGHTS` ничего не нужно:
     чаща раскладки не использует.
3. Если это отдельный режим в меню:
   - расширить `BattleMode` в [core/types.ts](../src/game/core/types.ts);
   - расширить `mode: z.enum(["skirmish","expedition"])` в `mapSchema` ([core/save/index.ts](../src/game/core/save/index.ts))
     Счётчики сюжета `sortie.started.<mode>` в [core/story/facts.ts](../src/game/core/story/facts.ts)
     подхватят новый режим сами;
